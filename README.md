## Что получил

**По методам** (на синтетических дефектах):
- **Огибающая вектора Парка** — лучший метод для обычных дефектов (дисбаланс, расцентровка, кольца, сепаратор):
  средние и сильные — 97–100 %, ловит даже часть слабых, ложных тревог 6 %.
- **ВЧ-огибающая с выбором полосы** — единственный рабочий метод для ударов, т. е. **царапин**:
  сильные — 100 %, средние — 47–84 %, слабые — почти нет.
- **Прямой спектр** — простой и дешёвый, но царапины почти не видит (0–18 %).
- **Вейвлет** — на этих данных хуже огибающей почти везде; полезен для картинок и проверки, что запись стационарна.
- **Итог:** нужна связка Парк + ВЧ-огибающая.

**По «Алтаю»:**
- Физического чипа нет — работаем на побитном эмуляторе (golden model) через KNP v1.0.0 в Docker.
- Сеть: 42 бинарных входа → 9 нейронов AltAILIF (6 — тип дефекта, 3 — степень), веса только −1/0/+1.
- Python кладёт веса и спайки в CSV → `docker exec` запускает сеть → обратно CSV с выстрелившими нейронами.
- Результат на 45 тестовых файлах: тип верно 76 %, степень 82 %, путаницы типов нет — все ошибки это пропущенные слабые дефекты.
  Эмулятор совпал с эталоном бит в бит.

1. Добавить в сеть признаки ВЧ-огибающей (частоты дефектов колец BPFO, BPFI) и переобучить.
2. Обучать сеть ещё и на ударных дефектах, не только на модуляции.
3. Подтянуть слабые дефекты (сейчас ловятся 2 из 12): понизить порог и проверить рост ложных тревог.
4. Проверить алгоритм на настоящих дефектах — исходные записи, вероятно, из датасета KAIST, где есть метки.
