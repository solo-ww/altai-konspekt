## Правила

1. Пишем своими словами. Непонятно — пишем вопрос с `- [ ]`, кто разобрался — отвечает и ставит `- [x]`.
2. Свои наблюдения подписываем: `> **Егор:** …`
3. Любое изменение — строчка в [ЖУРНАЛ.md](ЖУРНАЛ.md) + коммит с понятным сообщением.
4. Картинки — в папку `img/`.
